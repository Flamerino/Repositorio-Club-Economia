# Datos del Club de Economía UADE

**348 series** y **866.885 datos**, un archivo CSV por serie (`fecha, valor`), listos para abrir en Excel o Google Sheets. Se actualizan solos todas las semanas.

El detalle de cada serie (unidad, período, fuente y cómo se construye) está en [`INDICE.csv`](INDICE.csv).
